# Spotify Clone - Music Streaming App

Full-featured music streaming with audio player, playlists, search, and Stripe subscriptions.

## Features
- 🎵 Full audio player (Howler.js) - play/pause/seek/volume/shuffle/repeat
- 📋 Playlist CRUD
- 🔍 Real-time search
- 💳 Stripe subscriptions
- 🖤 Spotify-identical dark UI

## Tech Stack
- Next.js 14, Supabase, Howler.js, Stripe, Tailwind, Zustand

## Getting Started
```bash
npm install && cp .env.example .env.local && npm run dev
```
